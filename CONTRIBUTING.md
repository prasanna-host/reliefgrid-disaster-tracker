# Contributing to ReliefGrid

Thanks for helping improve ReliefGrid.

## Workflow

1. Open an issue or describe the improvement you plan to make.
2. Create a branch from `main`, for example `feature/better-validation`.
3. Keep each change focused and explain why it helps.
4. Test the page in a modern browser at desktop and mobile widths.
5. Check the browser console for errors.
6. Submit a pull request with a clear summary and testing notes.

## Contribution guidelines

- Keep the project lightweight and dependency-free unless a dependency is justified.
- Do not add real personal, medical, shelter, or emergency-response data.
- Label mock data clearly.
- Never describe this prototype as a live emergency dispatch system.
- For UI changes, include screenshots in the pull request when practical.
