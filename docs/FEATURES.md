# ReliefGrid Features

## Dashboard
Summarizes requests, tracked shelters, occupancy, and low-stock supplies.

## Resource Requests
Allows users to record a request, specify a location and quantity, and assign a priority.

## Shelter Directory
Displays sample shelter occupancy and capacity.

## Inventory
Shows stock levels and replenishment thresholds.

## Demo Limitations
Data is fictional and stored only in the current browser session. The prototype has no live emergency integrations.
