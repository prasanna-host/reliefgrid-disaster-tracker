# ReliefGrid — Disaster Relief Resource Tracker

## Overview
ReliefGrid is a student prototype designed to help coordinate disaster-relief resources, shelter capacity, inventory, and requests from field teams.

## Problem
During disasters, relief supplies and requests can be difficult to coordinate across shelters and response teams.

## Proposed Solution
ReliefGrid provides a unified dashboard to review sample shelter occupancy, inventory levels, and resource requests.

## Current Features
- Emergency response dashboard
- Shelter directory and capacity indicators
- Resource request creation and priority labels
- Inventory stock and replenishment thresholds
- Request filtering and recent activity

## Project Status
This is a front-end demonstration using fictional sample data. It is not connected to live emergency services or a backend.

## Future Improvements
- Persistent database
- Secure user authentication
- Real map integration
- Offline-friendly reporting
- Resource allocation and dispatch tracking
